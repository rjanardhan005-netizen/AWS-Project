502

Bad Gateway

Nginx could not connect to the upstream service.
This usually means the backend service name or port is incorrect.

🔍 Troubleshooting steps:

1. Check running containers: docker ps
2. Check Nginx logs: docker logs nginx-proxy
3. Inspect Nginx config: docker exec nginx-proxy cat /etc/nginx/conf.d/default.conf
4. Fix the config and reload: docker exec nginx-proxy nginx -s reload
